Diffy Feedback Fix Demo

This is the new demo for the feedback pass: stronger diff colors, silent left/right arrow support, and working collapse/expand backed by richer TUI diff context.

Fixed

  • Additions and deletions now use stronger foreground/background colors.
  • Left and right arrow keys now scroll horizontally in diff focus, while the footer still only shows h/l.
  • z toggles the collapsed context nearest the current scroll position.
  • Z expands all collapsed context, and pressing Z again collapses all.
  • TUI diffs now use --unified=80 so there is enough unchanged context to collapse/expand.
  • --raw keeps raw Git output and does not add the TUI context flag.

Verification

  • go test -count=1 ./... passed.
  • go build ./... passed.
  • go run . --summary worked after the feedback fixes.
  • go run . --raw --file render.go confirmed raw patch output still works.
