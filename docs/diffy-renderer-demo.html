Diffy IntelliJ-Style Renderer Demo

This demo shows the renderer work from docs/intellij-style-diff-renderer-plan.md: structured patch parsing, editor-like split panes, unified gutters, fixed horizontal scroll behavior, and collapsed unchanged context.

What changed

  • Raw patch metadata is parsed as structure and hidden from normal TUI rendering.
  • Split view is rendered as old/new editor panes with gutters and a pane boundary.
  • Unified view uses old/new line-number gutters instead of raw hunk headers.
  • Horizontal scroll moves code text while gutters and pane framing stay fixed.
  • Large unchanged regions collapse by default and can be expanded with z or Z.
  • --raw still prints the original Git patch output.

Verification

  • go test -count=1 ./... passed with local Go caches.
  • go build ./... passed with local Go caches.
  • go run . --summary reported the current repo change summary.
  • go run . --raw --file render.go confirmed raw Git output remains available.
