Diffy Search Implementation Report

Implemented the inline search design from docs/search-interaction-requirements.md, with the later label cleanup feedback applied.

Demo Video

The demo highlights the two key flows: sidebar filtering with selected-row highlighting, and diff search with the query and match count kept on one search row.

What Changed

  • / now opens inline search in the active pane instead of a centered prompt.
  • Sidebar search filters files, commits, and stashes as the query is typed.
  • Sidebar matches are highlighted without breaking the selected-row background.
  • Diff search highlights rendered diff matches across split or unified layout.
  • Diff search keeps / query and current/total on the same compact row.
  • enter locks the query, esc clears it, and n/N navigate diff matches.
